GUIDE DE DÉMARRAGE

Mets WIBN en route en 5 étapes

WIBN scrape Reddit/HackerNews, note les vraies frustrations et génère des idées de SaaS par IA. Chaque personne fait tourner sa propre instance, chez elle — voici comment passer de zéro à un dashboard qui tourne.

🎁

Giveaway — clés gratuites

Un nombre limité de clés WIBN (plan Pro, 90 jours) à distribuer. Un clic, une clé — premier arrivé, premier servi.

Chargement…
Colle-la sur /activate de ton instance.
1

Prérequis

Docker + Docker Compose (inclus avec Docker Desktop), une clé de licence WIBN (demande-la à qui te l'a partagée), et une clé Groq gratuite pour la génération d'idées par IA.

2

Cloner et lancer

git clone https://github.com/aboudou-cto-bloko/wibn.git
cd wibn
cp .env.example .env
# édite .env : au minimum GROQ_API_KEY et BETTER_AUTH_SECRET
docker compose up -d --build

Premier lancement = une à deux minutes (build + install). L'app tourne ensuite sur http://localhost:3001.

3

Activer ta licence

Ouvre l'app — sans licence active tu es redirigé vers /activate. Colle la clé qu'on t'a transmise (un token qui commence par eyJ...) et valide. Chaque clé ne déverrouille qu'une seule instance à la fois.

MessageCause / solution
« Clé invalide »Token mal copié — recopie-le en entier, sans retour à la ligne
« Licence expirée »Redemande une clé à qui te l'a fournie
« Déjà activée sur une autre instance »Désactive-la depuis l'ancienne instance (Réglages → Licence), ou redemande une clé
Pas encore de clé ? Le catalogue n'est pas en libre-service pour l'instant — contacte la personne qui t'a partagé WIBN pour qu'elle t'en génère une.
4

Créer ton compte

Après activation, direction /sign-up : nom, email, mot de passe.

Important : le tout premier compte créé sur une instance devient automatiquement administrateur. Crée le tien tout de suite après activation — sinon la première personne qui s'inscrit après toi héritera des droits admin à ta place.
5

Utiliser WIBN

Le pipeline, dans l'ordre : Scraping (Reddit/HN) → Scoring (painScore) → Clustering → Génération d'idées (Groq). Chaque étape tourne automatiquement (si activée dans Réglages) ou se déclenche à la main.

Dashboard
Vue d'ensemble, scores, actions rapides
Scraping
Catégories de subreddits à surveiller
Pain Points
Tout ce qui a été scrapé, trié par painScore
Clusters
Pain points regroupés par thème récurrent
Ideas
Idées de SaaS générées par l'IA à partir des clusters
Réglages
Licence, fonctionnalités, seuils de scoring

Questions fréquentes

Je veux ajouter d'autres utilisateurs sur mon instance

Ils peuvent créer un compte via /sign-up, mais seul le premier compte (admin) a accès au dashboard aujourd'hui — les comptes suivants n'ont pas encore d'interface dédiée.

Je veux déplacer WIBN vers un nouveau serveur

Sur l'ancienne instance : Réglages → Licence → Désactiver cette instance. Puis docker compose up sur la nouvelle machine et réactive la même clé sur /activate.

Ma clé expire bientôt, comment la renouveler ?

Contacte qui te l'a fournie pour une nouvelle clé — pas encore de renouvellement en libre-service.

J'ai perdu l'accès à mon compte admin

Avec un accès au serveur : renseigne ADMIN_EMAIL/ADMIN_PASSWORD/ADMIN_NAME dans .env puis docker compose restart app — le script de démarrage crée/promeut ce compte au boot.

Comment tout réinitialiser ?

docker compose down -v — ⚠️ supprime toutes les données.
